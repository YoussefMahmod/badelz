### How to Get 10 Venues (First 2 Weeks)

The venue acquisition strategy must be aggressive because venues = supply = what players come back for.

**Priority Targeting (Venues most likely to say yes):**

1. **Small independent courts (1-2 courts)** -- They have no booking system. They answer WhatsApp all day. They need this the most. They will say yes fastest.
2. **New venues (opened in last 3-6 months)** -- They are hungry for players and more open to trying new tools.
3. **Venues with active Instagram** -- They already invest in marketing, so they understand the value of an online presence.
4. **Venues with "Book via WhatsApp" in bio** -- This is literally an admission that they need a booking system.

**The Pitch Sequence:**

1. Follow their Instagram, like 3 posts
2. Watch their stories for 2-3 days (they see you in viewers)
3. Reply to a story with a genuine comment about their venue
4. Day 3-4: Send Version A DM
5. Day 6-7: Send Version C follow-up if no reply
6. If they reply with interest: Send them the link to an example venue page, offer to set up their page "in 5 minutes"
7. If they say yes: Get court count, prices, hours. Add them same day. Send them their live page link within hours.

**Objection Handling:**

| Objection | Response |
|-----------|----------|
| "مش محتاجين" | "مفيش أي التزام -- لاعبين جداد هيلاقوكم ويحجزوا. لو مجابش نتيجة مش هيكلفكم حاجة" |
| "عندنا سيستم" | "تمام -- بادلز مكمل مش بديل. اللاعبين اللي هيلاقوكم عندنا ده ترافيك زيادة" |
| "فيه عمولة؟" | "لا. صفر. اللاعب بيحجز عندنا وبيدفع عندكم في الملعب" |
| "هنفكر" | "تمام خالص -- بس عشان تقدروا تشوفوها، ده لينك ملعب شبيه: [link]. لو حبيتوا ابعتولي وأنا أضيفكم في دقايق" |
| "مش فاهمين هتستفيدوا إزاي" | "ببساطة: لاعبين جداد هيلاقوكم من غير ما تعملوا أي حاجة. زي ما المطاعم بتتحط على طلبات وإليفو عشان ناس أكتر تلاقيهم" |

### How to Get 50 Users (First 2 Weeks)

**The math:**
- You need ~200-300 visitors to convert 50 into active users (booking or lobby)
- Facebook group posts to 5-8 groups with 2-5K members each = potential reach of 15-40K
- If 1-2% click through = 150-800 visitors
- If 15-25% of visitors take an action = 25-200 active users

**The conversion funnel to optimize:**

1. **Click-through from Facebook/WhatsApp** -- Maximize with compelling copy and Arabic screenshots
2. **Page load** -- Must load in under 3 seconds on Egyptian 4G. Test this.
3. **Browse -> Action** -- The home page must immediately show venues and lobbies. Empty states kill conversion. Seed with real-looking data.
4. **Action -> Complete** -- The booking flow must be 3 taps max. Name, phone, confirm. No friction.

**Viral Loops That Amplify:**

1. **Lobby sharing**: Player creates lobby -> shares link on WhatsApp -> 3 friends open link -> 1 creates their own lobby = K-factor ~1.0
2. **Booking confirmation sharing**: After booking, prompt: "ابعت تأكيد الحجز لصحابك" with a WhatsApp share button
3. **"I play at" social proof**: Player cards showing where someone plays most -> venue gets free promotion

## 6. Key Metrics to Track (PostHog)

### Critical Week 1 Dashboard

PostHog autocapture is already enabled, which gives you pageviews and basic clicks. But you need to track these specific events to understand if the product is working:

**Acquisition Metrics (Are people finding you?)**

| Event | How to Track | Week 1 Target |
|-------|-------------|---------------|
| Unique visitors | PostHog automatic | 150-300 |
| Traffic source breakdown | PostHog referrer property (utm_source) | Know your #1 channel |
| PWA install prompt shown | Custom event | Track % |
| PWA installed | Custom event | 5-15 |

**UTM Strategy -- Tag every link you share:**
- Facebook groups: `?utm_source=facebook&utm_medium=group&utm_campaign=launch&utm_content=padel_egypt`
- WhatsApp: `?utm_source=whatsapp&utm_medium=message&utm_campaign=launch`
- Instagram: `?utm_source=instagram&utm_medium=story&utm_campaign=launch`
- Venue owner DMs: `?utm_source=instagram&utm_medium=dm&utm_campaign=venue_outreach`

**Activation Metrics (Are people doing the core action?)**

| Event | What to Track | Week 1 Target |
|-------|--------------|---------------|
| `venue_viewed` | User opened a venue detail page | 50+ |
| `booking_started` | User opened booking form | 20+ |
| `booking_completed` | User submitted a booking | 10-25 |
| `lobby_created` | User created a new lobby | 5-15 |
| `lobby_joined` | User joined an existing lobby | 10-30 |
| `lobby_shared` | User clicked share/copy lobby link | Track % of lobby creators |
| `coach_viewed` | User opened a coach profile | Track |
| `market_listing_created` | User listed an item for sale | 0-5 |
| `market_item_viewed` | User opened a marketplace listing | Track |

**Retention Signals (Will they come back?)**

| Event | What to Track | Why It Matters |
|-------|--------------|----------------|
| Return visit (Day 1, 3, 7) | PostHog cohort analysis | Are people coming back? |
| Second booking | `booking_completed` where user phone has previous booking | Repeat = product-market fit signal |
| Lobby -> Booking conversion | User who joined lobby later made a booking | Cross-feature flywheel working |
| Language toggle | Did they switch AR/EN? | Validates Arabic-first decision |

**Funnel to Build in PostHog (Day 1 Priority):**

```
Homepage Visit
  -> Browse Venues
    -> Venue Detail View
      -> Booking Form Opened
        -> Booking Completed

Homepage Visit
  -> Play/Lobby Page
    -> Lobby Created OR Lobby Joined
      -> Lobby Shared (WhatsApp)
```

**Drop-off Alert Thresholds:**
- If < 30% of homepage visitors click into browse or play: Your homepage is not compelling enough. Add more visible CTAs.
- If < 40% of venue viewers start booking: The venue page is not convincing, or the "book" CTA is not prominent enough.
- If < 60% of booking starters complete: There is friction in the booking form. Simplify.
- If < 20% of lobby creators share the link: The share flow is buried or broken.

### Numbers That Actually Matter in Week 1

Forget vanity metrics. These 5 numbers tell you if Badelz is working:

1. **Booking completion rate** (bookings / unique visitors) -- Target: > 5%
2. **Lobby share rate** (lobbies shared / lobbies created) -- Target: > 50%
3. **Day 3 return rate** (users who come back within 3 days / total users) -- Target: > 15%
4. **Venue page depth** (avg venue pages viewed per session) -- Target: > 2
5. **Time to first action** (seconds from first visit to first booking/lobby) -- Target: < 120 seconds

### What to Do If Numbers Are Bad

| Signal | Diagnosis | Fix |
|--------|-----------|-----|
| High traffic, low bookings | Booking flow has friction or venues are not compelling | Test on a friend's phone over their shoulder. Watch where they hesitate. |
| Low traffic | Posts are not getting clicks | Change the hook. Lead with the pain point, not the product. |
| People visit once, never return | No reason to come back | Push lobby feature harder. Lobbies create daily engagement. |
| Lobbies created but not shared | Share UX is broken or not obvious | Make the WhatsApp share button the biggest thing on the lobby page |
| Venue owners not replying | DM is too long or they do not trust you | Shorten DM. Include screenshot of their competitors on Badelz. FOMO works. |
